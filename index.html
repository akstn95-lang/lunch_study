아직 좌석이 없어요 설정 탭에서 명단을 등록하고 좌석을 배정해 주세요.

1명단 입력

한 줄에 학생 한 명씩 입력하세요. "번호 이름" 형식(예: 3 김민수)도 인식됩니다.

2좌석 배치 만들기

행/열 수를 정해 좌석판을 만든 뒤, 아래에서 좌석과 학생을 연결하세요.

3좌석에 학생 연결하기

좌석을 먼저 클릭한 뒤, 왼쪽 명단에서 학생 이름을 클릭하면 배정됩니다. 배정된 좌석은 오른쪽 위 × 로 해제할 수 있어요.

4입실기록 자동 전송

설정한 시간이 되면 그 시점의 입실 기록을 자동으로 전송합니다. 전송이 이뤄지려면 이 페이지(브라우저 탭)가 열려 있어야 합니다.

전송 시간
받는 이메일
완전 자동 전송 연결하기(구글 앱스 스크립트, 선택사항)

GAS 웹앱 URL을 입력하지 않으면, 설정한 시간에 메일 작성창만 자동으로 열리고 실제 전송은 직접 눌러야 합니다.
아래 스크립트를 구글 앱스 스크립트 편집기에 붙여넣고 "배포 → 웹 앱으로 배포"(액세스 권한: 모든 사용자)한 뒤, 발급된 URL을 아래에 입력하면 탭이 열려 있을 때 완전히 자동으로 전송됩니다.
